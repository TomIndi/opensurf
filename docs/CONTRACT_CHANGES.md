# Contract changes log

Additive changes to shared contract files. Format: `- [owner] file: change — reason`.
- [bsp-core] src/bsp/types.ts: added optional `BspFile.facesLump?: number` (LUMP_FACES or LUMP_FACES_HDR) — HDR-only maps have no LDR face lump; their faces' lightOfs then index `lightingHDR`, and the renderer needs to know which.
- [bsp-core] src/bsp/types.ts: added optional `BspFile.warnings?: string[]` — parse/validation problems (bad lump sizes, out-of-range indices, untested versions) for the loader to surface in `LoadedMap.warnings`.
- [materials] src/map/types.ts: added optional `MaterialDef.textureTransform`, `frames`/`frameRate`, `image2`/`fallbackColor2`/`textureTransform2`, `detail` (+ new `MaterialDetail` interface) — needed for in-game fidelity: $basetexturetransform scaling, AnimatedTexture proxies, WorldVertexTransition displacement blends ($basetexture2 by RenderBatch.alphas) and $detail textures. All optional; renderers that ignore them still get a correct base image.
- [movement] src/physics/movement.ts semantics (no contract file edited): `playerMove(..., frametime, ...)` takes the RAW tick interval and applies `ps.laggedMovement` itself (effective ft = frametime * laggedMovement). ARCHITECTURE "tick order" step 3 says the caller pre-multiplies — do only one: pass `tickInterval`. Also new optional export `movementOptions.rampbugFix` (default true) for a server cvar.
- [materials] src/map/types.ts: added optional `DecodedImage.compressed` (+ new `CompressedImage` interface: DXT1/3/5 mip chain) — opt-in `buildMaterials(..., { compressedTextures: true })` keeps the VTF's original DXT blocks so an S3TC-capable renderer can upload full-resolution textures with 4–8x less memory (surf_summer_ksf: 58 MB DXT instead of 315 MB RGBA). Default off; `data` stays a valid RGBA image (reduced size in that mode).
- [materials] src/map/types.ts: added optional `MaterialDef.envmap` (+ `MaterialEnvmap`), `MaterialDef.waterFogRange`, and `MapRenderData.cubemaps` (+ `CubemapDef`) — cubemap reflections ($envmap on glass, shiny ramps, neon grids) and water fog distances are part of the in-game look; `loadCubemaps(bsp, pak)` in bsp/materials.ts fills `cubemaps`. All optional.
- [bsp-render] src/map/types.ts: added optional `RenderProp.color`, `alpha`, `entity`, `area` and `ambientCube` — prop_dynamic entities (128 on surf_lt_omnific) carry rendercolor tints / renderamt, the game needs the entity index to toggle them, 3D-skybox props (surf_lt_omnific's 3dsb_* models) need their BSP area to be drawn in the sky pass, and props have no lightmap: vrad's leaf ambient cube at the prop's lighting origin is how the engine lights them. All optional; a renderer that ignores them still draws correct geometry.
- [bsp-render] src/map/types.ts: added optional `RenderBatch.decal` — info_overlay geometry (422 overlays on surf_lt_omnific: trims, signs, graffiti) is emitted as batches lying on the world surfaces; the flag tells the renderer to draw them with a depth bias after the opaque world. Optional; without it they still render (lifted 0.25 units off the surface).
- [game-world] src/map/types.ts: added `'map'` to the `ZoneSource` union — timer zones derived from the map's own conventionally named timer triggers (start_trigger / endzone / cpN_trigger / bonusNstart ...), used when there is no SurfTimer preset and to fill the courses/zone types a preset lacks. Additive: existing values unchanged.

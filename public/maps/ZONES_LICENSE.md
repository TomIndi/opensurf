# zones.json

`zones.json` contains timer zone coordinates converted from SurfTimer's
`scripts/mysql-files/ck_zones.sql` (https://github.com/surftimer/SurfTimer), which is licensed under the
GNU General Public License v3.0. The converted data is distributed under the same license (GPL-3.0-only).
It is regenerated by `scripts/build-catalog.mjs`.

`catalog.json` lists the public KSF surf map archive linked from https://github.com/OuiSURF/Surf_Maps
(file names and Google Drive ids) plus tiers from the KSF map spreadsheet. Map files are not
redistributed: the game downloads them on demand from the original archive.
